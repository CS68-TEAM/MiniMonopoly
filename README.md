# Mini Monopoly (TUI)

เกม Monopoly ย่อส่วน เล่นใน terminal คนเดียวสู้กับบอท 3 ตัว

## ติดตั้ง bun

```bash
bun install
bun run start
```

รัน test:
```bash
bun test
```

## เล่นยังไง?

เปิดมาจะมีเมนูให้กด `1` เริ่มเกมใหม่ หรือกด `2` เล่นต่อจากเซฟเก่า (ถ้ามี) กด `Q` ออกจากเกม

เกมนี้ไม่มีให้เลือกระดับความยาก จะเจอบอททั้ง 3 ระดับพร้อมกันในเกมเดียวเลย คือ 
-Bot (Easy)
-Bot (Normal)
-Bot (Hard) 
ใครล้มละลายก่อนก็ตกรอบ เหลือคนสุดท้ายคือผู้ชนะ

เล่นจบเกมนึงใช้เวลาประมาณ 15-20 นาที เร็วช้าขึ้นอยู่กับว่าตัดสินใจซื้อขายเร็วแค่ไหน

## ปุ่มควบคุมในเกมส์

| ปุ่ม | ทำอะไร |
|---|---|
| `ENTER` | ทอยลูกเต๋า |
| `B` | ซื้อที่ดินที่ยืนอยู่ ( ไม่มีเจ้าของเท่านั้น ) |
| `S` | ขายที่ดินที่ถูกที่สุดในมือ ( ได้คืนแค่ 30% ของราคาซื้อ ) |
| `T` | ยึดที่ดินคนอื่นที่ยืนอยู่ ( จ่ายเพิ่ม 50% ของราคา ) |
| `Ctrl+C` | ออกจากเกม |

## กระดานของเกมส์

32 ช่องวนรอบ แบ่งเป็น

| ช่องประเภท | จำนวน | ผลที่เกิด |
|---|---|---|
| ที่ดิน | 22 | ซื้อได้ถ้าว่าง / จ่ายค่าเช่าถ้ามีเจ้าของ |
| Chance | 4 | สุ่มเหตุการณ์ |
| ภาษี | 2 | เสียเงิน 15% ของเงินสดที่มีตอนนั้นทันที |
| GO | 1 | เก็บ $200 เมื่อผ่านหรือเหยียบ |
| คุก | 1 | ติดคุกทันที ข้ามเทิร์นถัดไป |
| ไปคุก | 1 | ติดคุกทันที ข้ามเทิร์นถัดไป |
| จุดพัก | 1 | ไม่มีผลอะไร |

ที่ดินแบ่งเป็น 6 ระดับราคา ยิ่งอยู่ไกลจาก GO ยิ่งแพง ค่าเช่าคิดเป็น 35% ของราคาที่ดินเสมอ

| ระดับ | ราคา | ค่าเช่า |
|---|---|---|
| T1 | $500 | $175 |
| T2 | $1,000 | $350 |
| T3 | $1,500 | $525 |
| T4 | $2,000 | $700 |
| T5 | $2,500 | $875 |
| T6 | $3,000 | $1,050 |

## เรื่องของเงิน
| รายการ | ค่า |
|---|---|
| เงินเริ่มต้น | $1,000 |
| ผ่าน/เหยียบ GO | +$200 |
| ขายที่ดิน | 30% ของราคาซื้อ |
| ยึดที่ดิน | +50% ของราคาเดิม (จำกัด 1 ครั้ง/เกม) |
| ซื้อที่ดินตรง ๆ สูงสุด | 7 ครั้ง |
| ถือที่ดินพร้อมกันสูงสุด | 5 แปลง |
| ค่าประกันตัวออกจากคุก | $250 |

## คุก

เหยียบช่อง "ไปคุก" จะติดคุกทันที ข้ามเทิร์นถัดไปเลยโดยไม่ต้องกด roll เอง

ออกจากคุกได้สองทาง จ่ายเงินประกันตัว $250 แล้วเล่นต่อในเทิร์นเดียวกันนั้นได้เลย หรือรอครบ 1 เทิร์นแล้วออกฟรี แล้วแต่การตัดสินใจของผู้เล่นหรือบอทตอนนั้น

## การ์ดสุ่ม (Chance)

เหยียบช่อง Chance ทีไรจะสุ่มเหตุการณ์ใหม่ทุกครั้ง ไม่ได้จั่วจาก deck คงที่ มีให้สุ่ม 6 แบบ

| เหตุการณ์ | โอกาส |
|---|---|
| เดินหน้า 5 ช่อง | 20% |
| ได้เงิน $100 | 15% |
| เสียเงิน $150 | 20% |
| ได้เงิน $50 | 20% |
| ถูกหวยได้ $300 | 10% |
| ถอยหลัง 3 ช่อง | 15% |

## เงินไม่พอจ่าย

ถ้าผู้เล่นเงินไม่พอจ่ายค่าเช่าหรือภาษี จะมีเมนูขึ้นมาให้เลือกขายที่ดินทีละแปลง หรือจะกด Declare Bankruptcy ยอมแพ้เลยก็ได้

ส่วนบอทถ้าเงินไม่พอจะขายที่ดินอัตโนมัติตามลำดับที่แต่ละตัวตั้งไว้ (แต่ละระดับความยากเลือกขายไม่เหมือนกัน) จนกว่าจะพ้นหนี้หรือล้มละลายไปเลย

ล้มละลายแล้วที่ดินทั้งหมดจะกลับไปเป็นของกลาง ไม่มีเจ้าของ ให้คนอื่นซื้อต่อได้

## เซฟเกม

เกมเซฟอัตโนมัติทุกจบเทิร์น ลงไฟล์ `save.json` ในโฟลเดอร์เดียวกัน เปิดเกมใหม่แล้วเลือก Resume (กด `2` หรือ `C`) เพื่อเล่นต่อจากจุดที่ค้างไว้ได้เลย ไม่ว่าจะหยุดตอนใครเป็นเทิร์นก็ตาม ระบบจะคืนตาให้ผู้เล่นเสมอ
