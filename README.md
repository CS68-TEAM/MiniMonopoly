# 🎲 Mini Monopoly (TUI)

เกม mini Monopoly (เกมส์เศรษฐีฉบับย่อ) เล่นใน terminal มีผู้เล่น `1` คน และบอท `3` ตัว มีความยากแตกต่างกัน ทุกคนมีเงินเริ่มต้นที่ `$1000` ลูกเต๋ามีเพียง `1` ลูก สามารถซื้อที่ดินได้และยังยึดที่ดินต่อจากผู้เล่นอื่นได้เช่นกัน ใครที่เหลือรอดเป็นคนสุดท้ายไม่ล้มละลายก่อน จะเป็นผู้ชนะ !!!

---
## How to Run

- ติดตั้ง [Bun](https://bun.sh) ก่อนเริ่มเล่น (หากไม่ติดตั้งจะไม่สามารถ run เกมได้)
- แนะนำ run ผ่าน Cmd จะแสดงผล TUI ได้ถูกต้อง ถ้าใช้ terminal อื่น (เช่น PowerShell, Windows Terminal) อาจเจอปัญหาในการแสดงผล


ติดตั้งแพ็กเกจก่อนเริ่มเล่นเกม

```bash
bun install
```

ใช้คำสั่งเพื่อเข้าสู่เกม Mini Monopoly

```bash
bun run start
```

---
## Game Overview

- ผู้เล่น 1 คน vs บอท 3 ตัว ที่มีระดับความยากต่างกัน (Easy / Normal / Hard) ปรากฏพร้อมกันในเกมเดียว
- กระดานวนรอบ 32 ช่อง ประกอบด้วยที่ดิน, Chance, Tax, GO, Jail, goToJail และ Free Park
- เหลือรอดจากการล้มละลายเป็นคนสุดท้ายคือผู้ชนะ
- เกมเซฟอัตโนมัติทุกจบเทิร์น สามารถออกแล้วกลับมาเล่นต่อได้

## Keybinds

### เมนูหลักของเกม
เมนูเริ่มเกม แล้วแต่ละปุ่มทำงานต่างกันยังไง?

| ปุ่ม | ทำอะไร |
|---|---|
| `1` | เริ่มเกมใหม่ |
| `2` | เล่นต่อจากเซฟเก่า (ถ้ามีการเล่นมาก่อน) |
| `Q` | ออกจากเกม |

### ปุ่มควบคุมภายในเกม 

| ปุ่ม | ทำอะไร |
|---|---|
| `ENTER` | ทอยลูกเต๋า |
| `B` | ซื้อที่ดินที่ยืนอยู่ ( ต้องไม่มีเจ้าของเท่านั้น ) |
| `S` | ขายที่ดินในมือ ( ได้คืนแค่ 30% ของราคาซื้อที่ดิน ) |
| `T` | ยึดที่ดินคนอื่นที่ยืนอยู่ ( จ่ายเพิ่ม 50% ของราคาที่ดิน ) |
| `Ctrl+C` | ออกจากเกม |
| `↑` / `↓` | เลื่อนดู Game Log ย้อนหลัง |

### Board (กระดานของเกม) 🕹

มีทั้งหมด 32 ช่องวนรอบ แบ่งเป็น 

| ช่องประเภท | จำนวน | ผลที่เกิด |
|---|---|---|
| ที่ดิน | 22 | ซื้อได้ถ้า**ไม่มี**เจ้าของ จ่ายค่าเช่าถ้า**มีเจ้าของ** |
| Chance | 4 | สุ่มการ์ด โชคดี🍀 โชคร้าย💀 |
| Tax | 2 | เสียเงิน 15% ของเงินสดที่มีตอนนั้นทันที |
| GO (start) | 1 | ได้รับ $200 เมื่อเดินผ่านหรือเหยียบ |
| Jail | 1 | ติดคุกทันที ข้ามเทิร์นถัดไป |
| goToJail | 1 | กลับไปติดคุกทันที ข้ามเทิร์นถัดไป |
| Free Park | 1 | ไม่มีผลอะไร สามารถเล่นเทิร์นต่อไปได้ปกติ |

```
และที่ดินทั้งหมด 22 ช่อง มี 6 ระดับราคา โดยแต่ละ Tier จะมีสีที่แตกต่างกัน แต่ละระดับราคาจะกระจายสลับกันอยู่บนกระดาน
เพื่อความสมดุลของเกม และค่าเช่าคิดเป็น 35% ของราคาที่ดินเสมอ
```

## การ์ดสุ่มลุ้นดวง 🌟
 เมื่อผู้เล่นเหยียบช่องสุ่มการ์ดลุ้นดวงเมื่อไหร่ การ์ดจะสุ่มเหตุการณ์ต่างใหม่ๆให้ลุ้นตลอด มีให้เลือกสุ่มกัน 10 แบบ

| การ์ด | โอกาส | ผลที่เกิด |
|---|---|---|
| Forward +5 | 10% | เดินหน้า 5 ช่อง |
| Lucky Day | 12% | วันแห่งโชคลาภได้รับ $100 |
| Medical Expenses | 13% | ค่ารักษาพยาบาลเสียเงิน $100 |
| Go to Start | 5% | กลับไปช่อง Start |
| Speed Ticket | 15% | เสียค่าปรับความเร็วเกินกำหนด $50 |
| Property Inspection | 10% | ค่าปรับ $50 + $50 ต่อจำนวนที่ดินที่มี |
| Market Boom | 10% | กำไรปันผล $50 + $50 ต่อจำนวนที่ดินที่มี |
| Unexpected Bill | 10% | บิลค่าใช้จ่ายฉุกเฉิน $150 |
| Lottery | 5% | ถูกหวยได้ $500 |
| Backward -3 | 10% | เดินถอยหลัง 3 ช่อง |

> หมายเหตุ : การ์ดที่พา "ผ่าน" GO โดยไม่หยุดจะไม่ได้เงิน ต่างจากทอยลูกเต๋าปกติ

### Mechanic 

| รายการ | ค่า |
|---|---|
| เงินเริ่มต้น | $1,000 |
| เดินผ่านหรือเหยียบ GO | +$200 (ถอยหลังไม่นับ) |
| ขายที่ดิน | ขายได้ 30% ของราคาซื้อ |
| ยึดที่ดินผู้เล่นอื่น | จ่ายเพิ่ม 50% ของราคาเดิม (จำกัด 1 ครั้ง/เกม) |
| ซื้อที่ดินที่ไม่มีเจ้าของสูงสุด | 7 ครั้ง |
| ถือที่ดินพร้อมกันสูงสุดได้ | 5 แปลง |
| ค่าประกันตัวออกจากคุก | จ่าย $250 |

## Jail (คุก) 🏛
  ### ☠️ ช่อง Jail 
```
หากผู้เล่นเหยียบช่อง "คุก" จะติดคุกทันที โดนข้ามเทิร์นถัดไป และอยู่ในคุก 1 วัน ไม่ต้องเล่นเองให้เสียแรง
หรือ จ่ายเงินประกันตัว $250 จะสามารถเล่นต่อในเทิร์นถัดไป โดยไม่ต้องติดคุก
```

### ☠️ ช่อง Go Jail
```
หากผู้เล่นเหยียบช่อง "ไปคุก" จะกลับไปที่ช่อง "คุก" และติดคุกทันที และเงื่อนไขเหมือนกันกับข้างบน
```

## เมื่อเกิดเงินไม่พอจ่าย 💸
### ♟️ Player
```
เมื่อผู้เล่นเงินไม่พอจ่ายค่าเช่าที่ดินหรือ Taxจะมีเมนูขึ้นมาให้เลือกขายที่ดินทีละแปลง หรือจะกด Declare Bankruptcy ยอมแพ้เลยนั่นเอง
```
### ♟️ Bot ทั้ง 3 ตัว
```
เมื่อบอทถ้าเงินไม่พอจะขายที่ดินอัตโนมัติตามลำดับที่แต่ละตัวตั้งไว้ แต่ละระดับความยากเลือกขายไม่เหมือนกัน จนกว่าจะพ้นหนี้หรือล้มละลายไปเลย
```
#### ❗❗ เมื่อผู้เล่นหรือบอทตัวใดตัวนึงล้มละลายแล้ว ที่ดินทั้งหมดจะกลับไปเป็นของกลาง ไม่มีเจ้าของให้คนอื่นซื้อต่อได้

### การ Save Game

เกมจะเซฟอัตโนมัติทุกครั้งที่จบเทิร์น ลงไฟล์ `save.json` ในโฟลเดอร์เดียวกัน เปิดเกมใหม่แล้วเลือก Resume 
กด `2`เพื่อเล่นต่อจากเดิมได้เลย ไม่ว่าจะหยุดตอนใครเป็นเทิร์นก็ตาม ระบบจะคืนตาให้ผู้เล่นเสมอ

## Known Limitations

- **ผู้เล่นเล่นได้แค่ 1 คนต่อเกม**
- **บอทตายตัว 3 ตัว** - ไม่สามารถปรับระดับความยากเองได้ ทุกเกมจะเจอ Easy, Normal, Hard เสมอ
- **ยึดที่ดิน จำกัด 1 ครั้ง/เกม ต่อผู้เล่น**
- **ขนาดของหน้าจอ** - Resolution ที่แนะนำคือ 1920x1080 เพื่อให้จอแสดงผลได้อย่างเต็มประสิทธิภาพ
- **ไม่มีบ้าน/โรงแรม** - ถือที่ดินเฉยๆ ค่าเช่าคงที่ตายตัว ไม่มีระบบอัปเกรดที่ดินให้แพงขึ้น
