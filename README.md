# Mini Monopoly (TUI)

เกม Mini Monopoly เป็นเกมเศรษฐีขนาดเล็ก เล่นใน terminal ผู้เล่น `1` คน สู้กับ บอท `3` ตัว
บอทแต่ละตัวจะมีความโหดแตกต่างกันทุกคนจะมีเงินเริ่มต้น `$1000` ทอยลูกเต๋าลูกเดียว ซื้อขายที่ได้ 
และซื้อที่ดินต่อจากผู้เล่นคนอื่นได้ เหลือรอดจากการล้มละลายเป็นคนสุดท้ายคือผู้ชนะ

## ก่อนเริ่มเกม ❗ 
ติดตั้งแพ็กเกจก่อนเริ่มเล่นเกมนะจ๊ะ
```bash
bun install
```

ใช้คำสั่ง ⬇ เริ่มเกมได้โลด
```bash
bun run start
```
## เข้าสู่หน้าเกมคุณจะเจอ 👀
เมนูเริ่มเกม😁 แล้วแต่ละปุ่มทำงานต่างกันยังไง 

| ปุ่ม | ทำอะไร |
|---|---|
| `1` | เพื่อเริ่มเกมใหม่ |
| `2` | เล่นต่อจากเกมเดิม แต่ถ้าพึ่งเริ่มจะ **ไม่สามารถ** กดได้ |
| `Q` | ออกจากเกม|

## อธิบายการเล่นคร่าวๆ
1. เกมนี้เป็นเกมที่ผู้เล่นต้องสู้กับบอท 3 ตัว เลือกไม่ได้น้าว่าจะเล่นกับบอทตัวไหน ต้องเจอทั้ง 3 ตัวเลย โดยความโหดแต่ละตัวจะมี easy normal hrad 
2. ลักษณะเกมเป็นการทอยลูกเต๋า 1 ลูก (1-6)

| รายการ | ค่า |
|---|---|
| เงินเริ่มต้น | $1,000 |
| ผ่าน/เหยียบ GO | +$200 |
| ขายที่ดิน | 30% ของราคาซื้อ |
| ยึดที่ดิน | +50% ของราคาเดิม (จำกัด 1 ครั้ง/เกม) |
| ซื้อที่ดินตรง ๆ สูงสุด | 7 ครั้ง |
| ถือที่ดินพร้อมกันสูงสุด | 5 แปลง |
| ค่าประกันตัวออกจากคุก | $250 |


## ช่องบนกระดาษ
ช่องบนกระดาน (32 ช่อง)
| ช่องประเภท | จำนวน | ผลที่เกิด |
|---|---|---|
| GO | 1 | ได้รับ $200 เมื่อเดินผ่านหรือเหยียบ |
| ที่ดิน | 22 | ซื้อได้ถ้า**ไม่มี**เจ้าของ จ่ายค่าเช่าถ้า**มีเจ้าของ** |
| Chance | 4 | สุ่มการ์ด โชคดี🍀 โชคร้าย💀 |
| ภาษี | 2 | เสียเงิน 15% ของเงินสดที่มีตอนนั้นทันที |
| คุก | 1 | ติดคุกทันที ข้ามเทิร์นถัดไป |
| ไปคุก | 1 | กลับไปติดคุกทันที ข้ามเทิร์นถัดไป |
| จุดพัก | 1 | ไม่มีผลอะไร สามารถเล่นเทิร์นต่อไปได้ปกติ |


ที่ดินแบ่งเป็น 6 ระดับราคา ยิ่งอยู่ไกลจาก GO ยิ่งแพง ค่าเช่าคิดเป็น 35% ของราคาที่ดินเสมอ

| ระดับ | ราคา | ค่าเช่า |
|---|---|---|
| T1 | $500 | $175 |
| T2 | $1,000 | $350 |
| T3 | $1,500 | $525 |
| T4 | $2,000 | $700 |
| T5 | $2,500 | $875 |
| T6 | $3,000 | $1,050 |

## ปุ่มอะไร

| ปุ่ม | ทำอะไร |
|---|---|
| `ENTER` | ทอยลูกเต๋า |
| `B` | ซื้อที่ดินที่ยืนอยู่ ( ไม่มีเจ้าของเท่านั้น ) |
| `S` | ขายที่ดินที่ถูกที่สุดในมือ ( ได้คืนแค่ 30% ของราคาซื้อ ) |
| `T` | ยึดที่ดินคนอื่นที่ยืนอยู่ ( จ่ายเพิ่ม 50% ของราคา ) |
| `Ctrl+C` | ออกจากเกม |
