# Mini Monopoly (TUI)

เกม Mini Monopoly เป็นเกมเศรษฐีขนาดเล็ก เล่นใน terminal ผู้เล่น `1` คน สู้กับ บอท `3` ตัว
บอทแต่ละตัวจะมีความโหดแตกต่างกันทุกคนจะมีเงินเริ่มต้น `$1000` ทอยลูกเต๋าลูกเดียว ซื้อขายที่ได้ 
และซื้อที่ดินต่อจากผู้เล่นคนอื่นได้ เหลือรอดจากการล้มละลายเป็นคนสุดท้ายคือผู้ชนะ

## ก่อนเริ่มเกม ❗ 
ติดตั้งแพ็กเกจก่อนเริ่มเล่นเกมนะจ๊ะ
```bash
bun install
```

ใช้คำสั่ง ⬇ เริ่มเกมได้โลด
```bash
bun run start
```
## เข้าสู่หน้าเกมคุณจะเจอ 👀
เมนูเริ่มเกม😁 แล้วแต่ละปุ่มทำงานต่างกันยังไง 

| ปุ่ม | ทำอะไร |
|---|---|
| `1` | เพื่อเริ่มเกมใหม่ |
| `2` | เล่นต่อจากเกมเดิม แต่ถ้าพึ่งเริ่มจะ **ไม่สามารถ** กดได้ |
| `Q` | ออกจากเกม|

## อธิบายการเล่น และสิ่งที่ทำได้ภายในเกม
สิ่งนี้จะบอกรายละเอียดต่างๆ ภายในเกมที่คุณอาจจะยังสงสัยอยู่ 🧐

> 1. ผู้เล่นทุกคนจะมีเงินเริ่มเกม $1000
>
> 2. เกมนี้เป็นเกมที่ผู้เล่นต้องสู้กับบอท 3 ตัว เลือกไม่ได้ว่าจะเล่นกับบอทตัวไหน ต้องเจอทั้ง 3 ตัวเลย โดยความโหดแต่ละตัวจะมี easy normal hard
> 
> 3. ลักษณะของลูกเต๋า จะมีทั้งหมด 6 หน้า ภายในเกมจะใช้ลูกเต๋า 1 ลูกเท่านั้น
>
> 4. รายละเอียดอื่นๆ อ่านได้ที่ ⬇

## ช่องบนกระดาษ
> เกมของเราจะมีช่องบนกระดาน 32 ช่อง แบ่งได้ตามด้านล่างนี้เลย
| ช่องประเภท | จำนวน | ผลที่เกิด |
|---|---|---|
| GO | 1 | ได้รับ $200 เมื่อเดินผ่านหรือเหยียบ |
| ที่ดิน | 22 | ซื้อได้ถ้า**ไม่มี**เจ้าของ จ่ายค่าเช่าถ้า**มีเจ้าของ** |
| Chance | 4 | สุ่มการ์ด โชคดี🍀 โชคร้าย💀 |
| ภาษี | 2 | เสียเงิน 15% ของเงินสดที่มีตอนนั้นทันที |
| คุก | 1 | ติดคุกทันที ข้ามเทิร์นถัดไป |
| ไปคุก | 1 | กลับไปติดคุกทันที ข้ามเทิร์นถัดไป |
| จุดพัก | 1 | ไม่มีผลอะไร สามารถเล่นเทิร์นต่อไปได้ปกติ |

```
และที่ดินทั้งหมด 22 ช่อง แบ่งเป็น 6 ระดับราคา นับแค่ช่องชื่อเมืองจะเป็นเป็นเพิ่มระดับ โดย T1-T5 จะนับทุก 4 ช่อง 
ส่วน T6 มีแค่ 2 ช่อง  ยิ่งอยู่ไกลจากจุดเริ่มต้นยิ่งแพง ค่าเช่าคิดเป็น 35% ของราคาที่ดินเสมอ
```
| ระดับ | ราคา | ค่าเช่า |
|---|---|---|
| T1 | $500 | $175 |
| T2 | $1,000 | $350 |
| T3 | $1,500 | $525 |
| T4 | $2,000 | $700 |
| T5 | $2,500 | $875 |
| T6 | $3,000 | $1,050 |

 ## กฎเกี่ยวกับที่ดิน
> ในระหว่างเกมผู้เล่นจะต้องเจอเงื่อนไขเกี่ยวกับการจัดแจงที่ดิน ที่ไม่รู้จะได้กำไรหรือขาดทุนกันแน่ ❗ 

| การกระทำ | ผลที่ได้ |
|---|---|
| เดินผ่านหรือเหยียบ GO | ได้รับเงิน $200 |
| ขายที่ดิน | ได้กำไร 30% ของราคาซื้อ |
| ยึดที่ดิน | จ่ายเพิ่ม 50% ของราคาเดิม (จำกัด 1 ครั้ง/เกม) |
| ซื้อที่ดินที่ไม่มีเจ้าของสูงสุด | 7 ครั้ง |
| มีที่ดินได้สูงสุด | 5 แปลง |
| ค่าประกันตัวออกจากคุก | จ่าย $250 |

## เงื่อนไขของการเข้าคุก
 ### ช่อง Jail 
```
หากผู้เล่นเหยียบช่อง "คุก" จะติดคุกทันที ข้ามเทิร์นถัดไป โดยไม่ต้องเล่นเองให้เสียแรง
หรือ จ่ายเงินประกันตัว $250 จะสามารถเล่นต่อในเทิร์นนั้นได้เลย
```

 ### ช่อง Go Jail
```
หากผู้เล่นเหยียบช่อง "ไปคุก" จะกลับไปที่ช่อง "คุก" และติดคุกทันที และเงื่อนไขเหมือนกันกับข้างบน
```

## การ์ดสุ่มลุ้นดวง

>เมื่อผู้เล่นเหยียบช่องสุ่มการ์ดลุ้นดวงเมื่อไหร่ การ์ดจะสุ่มเหตุการณ์ต่างใหม่ๆให้ลุ้นตลอด มีให้เลือกสุ่มกัน 10 แบบ
>มีแบบไหนบ้าง มาลุ้นกันว่าจะเจออะไร

| เหตุการณ์ | โอกาส |
|---|---|
| เดินหน้า 5 ช่อง | 10% |
| วันแห่งโชคลาภ $100 | 10% |
| ค่ารักษาพยาบาล $100 | 10% |
| กลับไปที่ GO | 10% |
| เสียค่าปรับความเร็วเกินกำหนด $50 | 10% |
| ค่าปรับ $50 + $50 ต่อจำนวนที่ดินที่มี | 10% |
| กำไรปันผล $50 + $50 ต่อจำนวนที่ดินที่มี | 10% |
| บิลค่าใช้จ่ายฉุกเฉิน $150 | 10% |
| ถูกหวยได้ $500 | 6% |
| เดินถอยหลัง 3 ช่อง | 7% |

## เงินไม่พอจ่าย

ถ้าผู้เล่นเงินไม่พอจ่ายค่าเช่าหรือภาษี จะมีเมนูขึ้นมาให้เลือกขายที่ดินทีละแปลง หรือจะกด Declare Bankruptcy ยอมแพ้เลยก็ได้

ส่วนบอทถ้าเงินไม่พอจะขายที่ดินอัตโนมัติตามลำดับที่แต่ละตัวตั้งไว้ (แต่ละระดับความยากเลือกขายไม่เหมือนกัน) จนกว่าจะพ้นหนี้หรือล้มละลายไปเลย

ล้มละลายแล้วที่ดินทั้งหมดจะกลับไปเป็นของกลาง ไม่มีเจ้าของ ให้คนอื่นซื้อต่อได้

## ปุ่มอะไร

| ปุ่ม | ทำอะไร |
|---|---|
| `ENTER` | ทอยลูกเต๋า |
| `B` | ซื้อที่ดินที่ยืนอยู่ ( ไม่มีเจ้าของเท่านั้น ) |
| `S` | ขายที่ดินที่ถูกที่สุดในมือ ( ได้คืนแค่ 30% ของราคาซื้อ ) |
| `T` | ยึดที่ดินคนอื่นที่ยืนอยู่ ( จ่ายเพิ่ม 50% ของราคา ) |
| `Ctrl+C` | ออกจากเกม |

## เซฟเกม

เกมเซฟอัตโนมัติทุกจบเทิร์น ลงไฟล์ `save.json` ในโฟลเดอร์เดียวกัน เปิดเกมใหม่แล้วเลือก Resume (กด `2` หรือ `C`) เพื่อเล่นต่อจากจุดที่ค้างไว้ได้เลย ไม่ว่าจะหยุดตอนใครเป็นเทิร์นก็ตาม ระบบจะคืนตาให้ผู้เล่นเสมอ
