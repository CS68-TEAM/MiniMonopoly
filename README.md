# Mini Monopoly (TUI)

เกม Mini Monopoly เป็นเกมเศรษฐีขนาดเล็ก เล่นใน terminal ผู้เล่น `1` คน สู้กับ บอท `3` ตัว
บอทแต่ละตัวจะมีความโหดแตกต่างกันทุกคนจะมีเงินเริ่มต้น `$1000` ทอยลูกเต๋าลูกเดียว ซื้อขายที่ได้ 
และซื้อที่ดินต่อจากผู้เล่นคนอื่นได้ เหลือรอดจากการล้มละลายเป็นคนสุดท้ายคือผู้ชนะ

## ก่อนเริ่มเกม ❗ 
ติดตั้งแพ็กเกจก่อนเริ่มเล่นเกมนะจ๊ะ
```bash
bun install
```

ใช้คำสั่ง ⬇ เริ่มเกมได้โลด
```bash
bun run start
```

ใช้คำสั่ง ⬇ สำหรับเทสไฟล์เกม
```bash
bun test
```

## เข้าสู่หน้าเกมคุณจะเจอ 👀
เมนูเริ่มเกม😁 แล้วแต่ละปุ่มทำงานต่างกันยังไง 

| ปุ่ม | ทำอะไร |
|---|---|
| `1` | เพื่อเริ่มเกมใหม่ |
| `2` | เล่นต่อจากเกมเดิม แต่ถ้าพึ่งเริ่มจะ **ไม่สามารถ** กดได้ |
| `Q` | ออกจากเกม|

## อธิบายการเล่น และสิ่งที่ทำได้ภายในเกม
สิ่งนี้จะบอกรายละเอียดต่างๆ ภายในเกมที่คุณอาจจะยังสงสัยอยู่ 🧐

> 1. ผู้เล่นทุกคนจะมีเงินเริ่มเกม $1000
>
> 2. เกมนี้เป็นเกมที่ผู้เล่นต้องสู้กับบอท 3 ตัว เลือกไม่ได้ว่าจะเล่นกับบอทตัวไหน ต้องเจอทั้ง 3 ตัวเลย โดยความโหดแต่ละตัวจะมี easy normal hard
> 
> 3. ลักษณะของลูกเต๋า จะมีทั้งหมด 6 หน้า ภายในเกมจะใช้ลูกเต๋า 1 ลูกเท่านั้น เดินตามจำนวนที่ทอยได้
>
> 4. รายละเอียดอื่นๆ อ่านได้ที่ ⬇

 ## กฎเกี่ยวกับที่ดิน
> ในระหว่างเกมผู้เล่นจะต้องเจอเงื่อนไขเกี่ยวกับการจัดแจงที่ดิน ที่ไม่รู้จะได้กำไรหรือขาดทุนกันแน่ ❗ 

| การกระทำ | ผลที่ได้ |
|---|---|
| เดินผ่านหรือเหยียบ GO | ได้รับเงิน $200 |
| ขายที่ดิน | ขายได้ 30% ของราคาซื้อ (ขาดทุน 70%) |
| ยึดที่ดิน | จ่ายเพิ่ม 50% ของราคาเดิม (จำกัด 1 ครั้ง/เกม) |
| ซื้อที่ดินที่ไม่มีเจ้าของสูงสุด | 7 ครั้ง |
| มีที่ดินได้สูงสุด | 5 แปลง |
| ค่าประกันตัวออกจากคุก | จ่าย $250 |

## เงื่อนไขของการเข้าคุก
 ### ช่อง Jail 
```
หากผู้เล่นเหยียบช่อง "คุก" จะติดคุกทันที โดนข้ามเทิร์นถัดไป และอยู่ในคุก 1 วัน ไม่ต้องเล่นเองให้เสียแรง
หรือ จ่ายเงินประกันตัว $250 จะสามารถเล่นต่อในเทิร์นถัดไป โดยไม่ต้องติดคุก
```

 ### ช่อง Go Jail
```
หากผู้เล่นเหยียบช่อง "ไปคุก" จะกลับไปที่ช่อง "คุก" และติดคุกทันที และเงื่อนไขเหมือนกันกับข้างบน
```

## การ์ดสุ่มลุ้นดวง

>เมื่อผู้เล่นเหยียบช่องสุ่มการ์ดลุ้นดวงเมื่อไหร่ การ์ดจะสุ่มเหตุการณ์ต่างใหม่ๆให้ลุ้นตลอด มีให้เลือกสุ่มกัน 10 แบบ
>มีแบบไหนบ้าง มาลุ้นกันว่าจะเจออะไร

| เหตุการณ์ | โอกาส |
|---|---|
| เดินหน้า 5 ช่อง | 10% |
| วันแห่งโชคลาภ $100 | 10% |
| ค่ารักษาพยาบาล $100 | 10% |
| กลับไปที่ GO | 10% |
| เสียค่าปรับความเร็วเกินกำหนด $50 | 10% |
| ค่าปรับ $50 + $50 ต่อจำนวนที่ดินที่มี | 10% |
| กำไรปันผล $50 + $50 ต่อจำนวนที่ดินที่มี | 10% |
| บิลค่าใช้จ่ายฉุกเฉิน $150 | 10% |
| ถูกหวยได้ $500 | 6% |
| เดินถอยหลัง 3 ช่อง | 7% |

## เมื่อเกิดเงินไม่พอจ่าย

### Player
```
เมื่อผู้เล่นเงินไม่พอจ่ายค่าเช่าที่ดิน หรือจ่ายภาษี จะสามารถเลือกขายที่ดินทีละแปลงได้ หรือยอมล้มละลาย หรือคือยอมแพ้นั่นเอง 
```
### Bot ทั้ง 3 ตัว
```
เมื่อบอทเงินไม่พอจ่ายค่าเช่าที่ดิน หรือจ่ายภาษี จะขายที่ดินอัตโนมัติตามที่แต่ละตัวได้ตั่งค่าไว้
และบอทแต่ละตัวระดับความยากในการเลือกซื้อขายแตกต่างกัน ตามความสามารถของแต่ละตัว
```
#### เมื่อผู้เล่นหรือบอทตัวใดตัวนึงล้มละลายแล้วที่ดินทั้งหมดจะกลับไปเป็นของกลาง ไม่มีเจ้าของ ให้คนอื่นซื้อต่อได้

## ปุ่มควบคุมภายในเกม
> ภายในเกมของเรา มีปุ่มตัวอักษรง่ายๆ ให้สามารถเล่นกันได้อย่างสะดวก แต่ละปุ่มมีหน้าที่อะไรกันนะ
c
| ปุ่ม | ทำอะไร |
|---|---|
| `ENTER` | ทอยลูกเต๋า |
| `B` | ซื้อที่ดินที่ยืนอยู่ ( ไม่มีเจ้าของเท่านั้น ) |
| `S` | ขายที่ดินที่ถูกที่สุดในมือ ( ได้กำไรคืนแค่ 30% ของราคาซื้อ ) |
| `T` | ยึดที่ดินคนอื่นที่ยืนอยู่ ( จ่ายเพิ่ม 50% ของราคาเดิม ) |
| `Ctrl+C` | ออกจากเกม |

## ระบบเซฟเกม

เกมจะเซฟอัตโนมัติทุกครั้งที่จบเทิร์น ลงไฟล์ `save.json` ในโฟลเดอร์เดียวกัน เปิดเกมใหม่แล้วเลือก Resume 
กด `2`เพื่อเล่นต่อจากเดิมได้เลย ไม่ว่าจะหยุดตอนใครเป็นเทิร์นก็ตาม ระบบจะคืนตาให้ผู้เล่นเสมอ
