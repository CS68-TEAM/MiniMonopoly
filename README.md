# Mini Monopoly (TUI)

เกม mini Monopoly (เกมส์เศรษฐีฉบับย่อ) เล่นใน terminal มีผู้เล่น 1 คน และบอทที่มีความยากแตกต่างกัน ทุกคนมีเงินเริ่มต้นที่ $1000 ลูกเต๋ามีเพียง 1 ลูก สามารถซื้อที่ดินได้และยังยึดที่ดินต่อจากผู้เล่นอื่นได้เช่นกัน ใครที่เหลือรอดเป็นคนสุดท้ายไม่ล้มละลายก่อน จะเป็น! ผู้ชนะ !!!

---

## Game Overview

- ผู้เล่น 1 คน (มนุษย์) vs บอท 3 ตัว ที่มีระดับความยากต่างกัน (Easy / Normal / Hard) ปรากฏพร้อมกันในเกมเดียว
- กระดานวนรอบ 32 ช่อง ประกอบด้วยที่ดิน, Chance, Tax, GO, Jail, goToJail และจุดพัก
- อยู่รอดจนเหลือคนสุดท้ายที่ไม่ล้มละลายชนะในเกมนั้น
- ใช้เวลาเล่นประมาณ 15–20 นาทีต่อเกม ขึ้นอยู่กับความเร็วในการตัดสินใจซื้อขาย
- เกมเซฟอัตโนมัติทุกจบเทิร์น สามารถออกแล้วกลับมาเล่นต่อได้

---

## Requirements

- ติดตั้ง [Bun](https://bun.sh) ก่อนเริ่มเล่น (จำเป็นมากๆ ถ้าไม่ติดตั้งจะไม่สามารถ run เกมได้)
- แนะนำใช้ Cmd รัน จะแสดงผล TUI ได้ถูกต้อง ไม่เพี้ยน

## Game Rules

### เมนูหลักของเกม

| ปุ่ม | ทำอะไร |
|---|---|
| `1` | เริ่มเกมใหม่ |
| `2` | เล่นต่อจากเซฟเก่า (ถ้ามีการเล่นมาก่อน) |
| `Q` | ออกจากเกม |

### ปุ่มควบคุมภายในเกม 

| ปุ่ม | ทำอะไร |
|---|---|
| `ENTER` | ทอยลูกเต๋า |
| `B` | ซื้อที่ดินที่ยืนอยู่ ( ต้องไม่มีเจ้าของเท่านั้น ) |
| `S` | ขายที่ดินที่ถูกที่สุดในมือ ( ได้คืนแค่ 30% ของราคาซื้อที่ดิน ) |
| `T` | ยึดที่ดินคนอื่นที่ยืนอยู่ ( จ่ายเพิ่ม 50% ของราคาที่ดิน ) |
| `Ctrl+C` | ออกจากเกม |

### Bot (บอท) 👾

เกมนี้ไม่มีให้เลือกระดับความยาก แต่จะเจอบอททั้ง 3 ระดับพร้อมกันในเกมเดียว:

| Bot 3 ตัว |
|---|
| `Easy` |
| `Normal` |
| `Hard` |

ใครล้มละลายก่อนก็ตกรอบ เหลือคนสุดท้ายคือผู้ชนะ !!!

### Board (กระดานของเกม) 🕹

มีทั้งหมด 32 ช่องวนรอบ แบ่งเป็น :

| ช่องประเภท | จำนวน | ผลที่เกิด |
|---|---|---|
| ที่ดิน | 22 | ซื้อได้ถ้าหากว่าง / จ่ายค่าเช่าถ้ามีเจ้าของ |
| Chance | 4 | สุ่มเหตุการณ์ |
| Tax | 2 | เสียเงิน 15% ของเงินสดที่มีตอนนั้นทันที |
| GO | 1 | เก็บ $200 เมื่อผ่าน หรือ เหยียบ |
| Jail | 1 | ติดคุกทันที และ ข้ามเทิร์นถัดไป |
| goToJail | 1 | ติดคุกทันที และ ข้ามเทิร์นถัดไป |
| จุดพัก | 1 | ไม่มีผลอะไร |

ที่ดินแบ่งเป็น 6 ระดับราคายิ่งอยู่ไกลจาก GO ยิ่งแพง ค่าเช่าคิดเป็น 35% ของราคาที่ดินเสมอ :

| ระดับ | ราคา | ค่าเช่า |
|---|---|---|
| T1 | $500 | $175 |
| T2 | $1,000 | $350 |
| T3 | $1,500 | $525 |
| T4 | $2,000 | $700 |
| T5 | $2,500 | $875 |
| T6 | $3,000 | $1,050 |

### Monney (เงิน) 💶

| รายการ | ค่า |
|---|---|
| เงินเริ่มต้น | $1,000 |
| ผ่าน/เหยียบ GO | +$200 (ถอยหลังไม่นับ) |
| ขายที่ดิน | 30% ของราคาซื้อ |
| ยึดที่ดินผู้เล่นอื่น | +150% (จำกัด 1 ครั้ง/เกม) |
| ซื้อที่ดินตรง ๆ ได้สูงสุด | 7 ครั้ง |
| ถือที่ดินพร้อมกันสูงสุดได้ | 5 แปลง |
| ค่าประกันตัวออกจากคุก | $250 |

### Jail (คุก) 🏛

หากเหยียบช่อง "goToJail" จะติดคุกทันที และข้ามเทิร์นถัดไปเลยโดยไม่ต้องกด roll เอง ออกจากคุกได้สองทาง : จ่ายเงินประกันตัว $250 แล้วเล่นต่อในเทิร์นเดียวกันนั้นได้เลย หรือรอครบ 1 เทิร์นแล้วออกฟรี แล้วแต่การตัดสินใจของผู้เล่นหรือบอทตอนนั้น

### Chance (การ์ดสุ่ม) 🃏

เหยียบช่อง Chance ทีไรจะสุ่มเหตุการณ์ใหม่ทุกครั้ง ไม่ได้จั่วจาก deck คงที่ มีสุ่ม 6 แบบ:

| เหตุการณ์ | โอกาส |
|---|---|
| เดินหน้า 5 ช่อง | 20% |
| ได้เงิน $100 | 15% |
| เสียเงิน $150 | 20% |
| ได้เงิน $50 | 20% |
| ถูกหวยได้ $300 | 10% |
| ถอยหลัง 3 ช่อง | 15% |

### หากเงินไม่พอจ่าย 🥶

- ถ้าผู้เล่นเงินไม่พอจ่ายค่าเช่าที่ดินหรือ Tax จะมีเมนูขึ้นมาให้เลือกขายที่ดินทีละแปลง หรือจะกด Declare Bankruptcy ยอมแพ้เลยก็ได้ 

- ส่วนบอทถ้าเงินไม่พอจะขายที่ดินอัตโนมัติตามลำดับที่แต่ละตัวตั้งไว้ (แต่ละระดับความยากเลือกขายไม่เหมือนกัน) จนกว่าจะพ้นหนี้หรือล้มละลายไปเลย

>ล้มละลายแล้วที่ดินทั้งหมดจะกลับไปเป็นของกลาง ไม่มีเจ้าของ ให้คนอื่นซื้อต่อได้

### การ Save Game

>เกมเซฟอัตโนมัติทุกจบเทิร์น ลงไฟล์ `save.json` ในโฟลเดอร์เดียวกัน เปิดเกมใหม่แล้วเลือก Resume (กด `2`) เพื่อเล่นต่อจากจุดที่ค้างไว้ได้เลย ไม่ว่าจะหยุดตอนใครเป็นเทิร์นก็ตาม ระบบจะคืนตาให้ผู้เล่นเสมอ

## How to Run

> **แนะนำ :** รันเกมผ่าน **Command Prompt (Cmd)** จะแสดงผล TUI ได้ถูกที่สุด ไม่เพี้ยน ถ้าใช้ terminal อื่น (เช่น PowerShell, Windows Terminal) อาจเจอปัญหาการแสดงผลกระดานหรือสีเพี้ยนได้ 

ติดตั้งแพ็กเกจก่อนเริ่มเล่น:

```bash
bun install
```

รันเพื่อเข้าสู่เกม Mini Monopoly:

```bash
bun run start
```

## Known Limitations

- **ผู้เล่นเล่ยได่้แค่ 1 คนต่อเกม** 
- **บอทตายตัว 3 ระดับ** — ไม่สามารถเลือกจำนวนบอทหรือปรับระดับความยากเองได้ ทุกเกมจะเจอ Easy + Normal + Hard เสมอ
- **Chance เป็นการสุ่ม** — ไม่ใช่ deck คงที่ เหตุการณ์เดียวกันอาจสุ่มซ้ำติดกันได้ 
- **ยึดที่ดิน (Take) จำกัด 1 ครั้ง/เกม ต่อผู้เล่น** 
- **Save file เดียว (`save.json`)** — เซฟทับทุกครั้ง และไม่มี backup
