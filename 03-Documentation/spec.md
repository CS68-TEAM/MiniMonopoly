# Spec - ข้อมูลจำเพาะทางเทคนิค

## 1. กติกา ( Game Constants )

ค่ากติกาหลักอยู่ที่ `Game.ts` (export const) ส่วนราคาและค่าเช่าที่ดินอยู่ที่ `ui/Board32.ts` ( `COLOR_TIERS` )

| ค่าคงที่ | ค่า | ความหมาย |
| --- | --- | --- |
| **จำนวนผู้เล่น** | 4 | ต้องมีผู้เล่นจำนวนรวมแล้วจำนวน 4 คนเท่านั้น |
| **จำนวนช่อง** | 32 | ความยาวของ `Board.tiles` |
| **เงินเริ่มต้น** | 1000 | default ของ `Player` |
| **ลูกเต๋า** | 1–6 | `rollDice()` ทอยลูกเดียว |
| **`START_BONUS`** | 200 | ดูเงื่อนไขในหัวข้อ 1.3 |
| **`JAIL_BAIL_AMOUNT`** | 250 | ค่าประกันตัวออกจากคุก |
| **`TAKEOVER_MULTIPLIER`** | 1.5 | ราคายึดที่ดิน = `ceil(price x 1.5)` |
| **`TAKEOVER_LIMIT`** | 1 | ยึดได้ 1 ครั้ง/เกม/ผู้เล่น |
| **`MAX_PROPERTIES`** | 5 | ถือที่ดินได้สูงสุดพร้อมกัน |
| **`MAX_DIRECT_PURCHASES`** | 7 | ซื้อตรงได้สูงสุดตลอดเกม (นับสะสม ไม่ลดเมื่อขายคืน การยึดไม่นับ) |
| **`SELL_RATE`** | 0.3 | ขายคืนได้ `floor(price x 0.3)` โดย `price` คือราคาปกติ ไม่ใช่ราคาที่จ่ายตอนยึด |
| **`TAX_RATE`** | 0.15 | ช่อง Tax เก็บ `ceil(เงินสดปัจจุบัน x 0.15)` |
| **ตำแหน่งคุก** | ช่อง 8 | `goToJail` วาร์ปผู้เล่นไปช่อง 8 แล้วติดคุก (เลข 8 เขียนตรงๆ ในโค้ด ไม่ได้เป็นค่าคงที่) |

### 1.1 ผู้เล่น

| ID | Kind | ควบคุมโดย |
| --- | --- | --- |
| `human` | Human | ผู้เล่น |
| `easy` | AI Easy | `EasyAI` |
| `normal` | AI Normal | `NormalAI` |
| `hard` | AI Hard | `HardAI` |

*สถานะผู้เล่น:* `active` กับ `jailed` สลับกันได้ (ติดคุก/ออกจากคุก) และจาก `active` หรือ `jailed` ไปเป็น `bankrupt` ได้ ซึ่งเป็นสถานะสุดท้าย

### 1.2 ชนิดช่อง

* **`start`:** ได้ `START_BONUS`
* **`property`:**
* ว่าง: Human ได้ popup ให้เลือกซื้อ ส่วนบอทตัดสินใจเองตามระดับ
* มีเจ้าของอื่น: จ่ายค่าเช่า (`rent`)
* ของตัวเอง: ไม่เกิดอะไร


* **`tax`:** จ่าย 15% ของเงินสดปัจจุบัน (ปัดขึ้น)
* **`jail`:** ติดคุก
* **`goToJail`:** ย้ายไปช่อง 8 แล้วติดคุก
* **`chance`:** จั่วการ์ด Chance ทันที
* **`parking`:** ปลอดภัย ไม่เกิดอะไร

### 1.3 การเดินและโบนัส START

* ตำแหน่งใหม่ = `(ตำแหน่งเดิม + แต้มเต๋า) mod 32`
* ได้ `START_BONUS` ในสองกรณีเท่านั้น และไม่ซ้อนกัน:
  1. เดินข้าม GO ด้วยการทอยเต๋า (ตำแหน่งใหม่ < ตำแหน่งเดิม และไม่ใช่ช่อง 0)
  2. หยุดพอดีที่ช่อง 0 (ได้จากผลของช่อง `start`) รวมถึงการ์ด Go to Start ที่ย้ายไปลงช่อง 0



### 1.4 คุก

1. ติดคุกจากช่อง `jail` หรือ `goToJail` การติดคุกทำให้เทิร์นนั้นจบทันที
2. เทิร์นถัดไปของคนที่ติดคุก:
* ถ้าเคยข้ามเทิร์นแล้ว (`stayinjailed = true`) ออกจากคุกแล้วทอยเต๋าเดินปกติ
* ถ้าเลือกจ่ายประกันและมีเงิน ≥ 250 จ่าย 250 แล้วทอยเต๋าเดินในเทิร์นนั้นเลย
* ถ้าไม่จ่าย (หรือเงินไม่ถึง 250) ข้ามเทิร์นและตั้ง `stayinjailed = true`


3. Human เลือกเองว่าจะจ่ายประกันหรือไม่ ถ้าไม่ได้เลือกถือว่าไม่จ่าย บอทตัดสินด้วย `decideJail` (ดูหัวข้อ 2)

### 1.5 เงื่อนไขซื้อที่ดิน

ซื้อไม่ได้ถ้าข้อใดข้อหนึ่งเป็นจริง (ตรวจตามลำดับนี้):

1. ที่ดินมีเจ้าของแล้ว (`already owned`)
2. เงินไม่พอ (`not enough money`)
3. ถือที่ดินครบ 5 แปลงแล้ว (`max 5 properties`)
4. ซื้อตรงครบ 7 ครั้งแล้ว (`max 7 purchases`)

### 1.6 เงื่อนไขยึดที่ดิน (Takeover)

ต้องผ่านทุกข้อ:

* ที่ดินมีเจ้าของ และเจ้าของไม่ใช่ผู้ยึด
* ผู้ยึดถือที่ดินน้อยกว่า 5 แปลง
* ราคาที่เสนอไม่ต่ำกว่า `ceil(price x 1.5)` และผู้ยึดมีเงินพอ
* ผู้ยึดยังไม่เคยยึดในเกมนี้

> *เจ้าของเดิมได้รับเงินเต็มจำนวนที่ผู้ยึดจ่าย การยึดไม่นับเป็น "ซื้อตรง" ฝั่ง Human เริ่มจากปุ่ม T (`startTakeover`) แล้วยืนยันใน popup*

### 1.7 เงินติดลบและล้มละลาย

* ค่าเช่า / Tax / การ์ด Chance ที่จ่ายเงินทำให้เงินติดลบ เข้าสู่กระบวนการปิดหนี้ กรณีค่าเช่า เจ้าของที่ดินได้รับเท่าที่ผู้จ่ายมีจริงเท่านั้น (ไม่เกินเงินสดของผู้จ่าย)
* **Human** ที่ยังมีที่ดิน เข้าสถานะ `pendingDebt` เลือกขายทีละแปลง (ได้ 30%) จนเงิน ≥ 0 หรือประกาศล้มละลายเอง
* **Human** ที่ไม่มีที่ดินเหลือและเงินติดลบ ล้มละลายทันที
* **บอท** ขายอัตโนมัติตามลำดับความสำคัญ (`sellPriority`) และหยุดทันทีที่เงิน ≥ 0
* ถ้าขายหมดแล้วยังติดลบ ล้มละลาย ที่ดินทั้งหมดกลับเป็นที่ว่าง (`owner = null`) ซื้อได้ใหม่ เงินตั้งเป็น 0 และถูกข้ามในลำดับเทิร์น
* เกมจบเมื่อเหลือผู้เล่นที่ไม่ล้มละลายคนเดียว คนนั้นเป็นผู้ชนะ

### 1.8 การ์ด Chance

ความน่าจะเป็นรวม = 1.00

| การ์ด | โอกาส | ผล |
| --- | --- | --- |
| **Forward +5** | 10% | เดินหน้า 5 ช่อง แล้วประมวลผลช่องที่ตกใหม่ |
| **Lucky Day** | 12% | ได้ $100 |
| **Medical Expenses** | 13% | จ่าย $100 |
| **Go to Start** | 5% | ย้ายไปช่อง START (ช่อง 0) และได้ `START_BONUS` |
| **Speed Ticket** | 15% | จ่าย $50 |
| **Property Inspection** | 10% | จ่าย `(จำนวนที่ดินที่ถือ + 1) x 50` |
| **Market Boom** | 10% | ได้ `(จำนวนที่ดินที่ถือ + 1) x 50` |
| **Unexpected Bill** | 10% | จ่าย $150 |
| **Lottery** | 5% | ได้ $500 |
| **Backward -3** | 10% | ถอยหลัง 3 ช่อง แล้วประมวลผลช่องที่ตกใหม่ |

> **หมายเหตุ:**
> * ถ้าการ์ดย้ายไปตกช่อง Chance อีกช่อง จะไม่จั่วซ้ำ
> * การ์ดที่จ่ายเงินทั้งหมดใช้กลไกเดียวกับ Tax จึงเข้ากระบวนการปิดหนี้ได้เหมือนกัน
> * Property Inspection และ Market Boom บวก 1 เข้าไปในจำนวนที่ดิน ทำให้แม้ไม่มีที่ดินก็ยังจ่ายหรือได้ $50
>

## 2. พฤติกรรมบอท

| หัวข้อ | Easy | Normal | Hard |
| --- | --- | --- | --- |
| **ซื้อที่ว่าง** | เงินเหลือหลังซื้อ ≥ 150 และ ROI > เกณฑ์ | เงินเหลือ ≥ 150, ค่าเช่า ≥ 30, ถือ < 5 แปลง | ซื้อทุกครั้งที่เงินพอ |
| **ยึดที่ดิน** | "ตามหลังคนรวยสุด", เงินเหลือ ≥ 150, ROI > เกณฑ์ | เงินเหลือ ≥ 150, ค่าเช่า ≥ 30, ถือ < 5 แปลง | ยึดทุกครั้งที่เงินพอ |
| **จ่ายประกันคุก** | เงินเหลือ ≥ 100 และ (ตามหลัง หรือถือ ≥ 3 แปลง) | เงินเหลือ ≥ 300 | ไม่จ่ายเลย |
| **ลำดับขายเมื่อติดหนี้** | `rent / price` ต่ำสุดก่อน | ค่าเช่าต่ำสุดก่อน | ราคาถูกสุดก่อน |

* **สูตร ROI ของ Easy:** `rent x 4 − price x 0.25` (คิดจากราคาปกติ แม้ตอนยึด) เกณฑ์คือ 0 (นำอยู่) หรือ −20 (ตามหลัง) โดยคำว่า *"ตามหลัง"* หมายถึงเงินของบอท < เงินของคู่แข่งที่ยังไม่ล้มละลายและรวยที่สุด

> **ข้อสังเกตจากตัวเลขบนกระดานปัจจุบัน:**
> * ROI ของ Easy เป็นบวกเสมอทุกสี (เท่ากับ `1.15 x price`) เงื่อนไข ROI จึงไม่เคยกันการซื้อ ตัวที่กันจริงคือเงินสำรอง 150 (และการ "ตามหลัง" ในกรณียึด)
> * `GOOD_RENT_THRESHOLD = 30` ของ Normal ต่ำกว่าค่าเช่าต่ำสุดบนกระดาน (175) จึงไม่เคยกันการซื้อเช่นกัน
> * เพราะค่าประกันคือ 250 บอทที่จะจ่ายประกันได้ต้องมีเงินก่อนจ่ายอย่างน้อย 350 (Easy) หรือ 550 (Normal)
> * มีแค่ Normal ที่ตรวจ `MAX_PROPERTIES` เอง ส่วน Easy และ Hard ปล่อยให้ `Game` ปฏิเสธแทน
> * ทุกบอทต้องผ่านข้อจำกัดของกติกาหลักเสมอ เพราะการซื้อและยึดจริงทำที่ `Game.buy()` / `Game.takeOver()`
>

## 3. ไฟล์เสียง (Assets)

โฟลเดอร์ `assets/` เก็บไฟล์ `.wav` โดยเสียงหลายอย่างจะเล่นเฉพาะเมื่อเหตุการณ์เกี่ยวกับ Human เท่านั้น

| เหตุการณ์ | ไฟล์ | หมายเหตุ |
| --- | --- | --- |
| **ทอยเต๋า** | `diceroll.wav` | เล่นทุกเฟรมของแอนิเมชัน (9 ครั้งต่อการทอย) |
| **เสียงแต้มเต๋า** | `1.wav` – `6.wav` | ตามแต้มที่ได้ |
| **ถึงตาคุณ** | `round.wav` (82%), `yourturn.wav` (18%) | สุ่มแบบถ่วงน้ำหนัก |
| **ซื้อที่ดิน** | `buy.wav` | เล่นทุกครั้งที่มีการซื้อ ไม่ว่าใครซื้อ |
| **ค่าเช่า (Human จ่าย)** | `sadjung.wav` (30%), `payrent.wav` (70%) | สุ่มแบบถ่วงน้ำหนัก |
| **จ่ายค่าเช่า (ทุกคน)** | `money.wav` | **ไฟล์นี้ไม่มีใน `assets/**` เล่นทุกครั้งที่จ่ายค่าเช่า ไม่ว่าใครจ่าย |
| **ได้เงิน** | `receivedmoney.wav` | เล่นทุกครั้งที่ `addMoney` ไม่ว่าใครได้ |
| **โดนยึดที่ดิน** | `noprop.wav` (50%), `takeover.wav` (50%) | เมื่อ Human เป็นเจ้าของเดิม |
| **ติดคุก** | `jail.wav` | เฉพาะ Human |
| **Chance** | `chance.wav` | เฉพาะ Human |
| **เริ่มเกม / ชนะ / แพ้** | `start.wav` / `win.wav` / `lost.wav` | `win` เล่นเมื่อ Human ชนะ, `lost` เล่นเมื่อ Human ล้มละลาย |
| **เดิน** | `move.wav` |  |
