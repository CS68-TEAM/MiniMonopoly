# Requirements

รายการสิ่งที่ระบบต้องทำได้ ใช้เลข อ้างอิงจาก test หรือ commit ได้

## Functional Requirements

| ID | ข้อกำหนด |
|---|---|
| FR-1 | เกมต้องมีผู้เล่น 4 คนพอดีประกอบด้วย 1 player + บอท Easy, Normal, Hard |
| FR-2 | ผู้เล่นทอยลูกเต๋า 1 ลูก (1–6) แล้วเดินบนกระดาน 32 ช่องแบบวนรอบ |
| FR-3 | ผู้เล่นได้ START_BONUS เมื่อเดินผ่านหรือหยุดที่ GO |
| FR-4 | ซื้อที่ดินว่างที่ยืนอยู่ได้ จำนวนที่ดินที่ถือ (สูงสุด 5) / จำนวนครั้งซื้อตรง (สูงสุด 7) |
| FR-5 | เหยียบที่ดินคนอื่นแล้วจ่ายค่าเช่าอัตโนมัติ |
| FR-6 | ยึดที่ดิน (takeover) โดยจ่าย 50% ของราคา จำกัด 1 ครั้ง/เกม/ผู้เล่น และต้องถือที่ดินไม่เกินจำนวนสูงสุด |
| FR-7 | ขายที่ดินคืนได้ 30% ของราคาซื้อ |
| FR-8 | ช่อง Tax เก็บ 15% ของเงินสดปัจจุบัน |
| FR-9 | ช่อง Chance สุ่มการ์ดตามความน่าจะเป็นแล้วมีผลทันที |
| FR-10 | Jail / Go Jail จ่ายประกันตัว (250) หรือข้ามเทิร์นแล้วออกเอง |
| FR-11 | เงินติดลบ ผู้เล่นสามารถเลือกขายที่ดินทีละแปลงหรือประกาศล้มละลายได้เลย ส่วนบอทจะคำนวณและขายอัตโนมัติ |
| FR-12 | ผู้เล่นที่ล้มละลายถูกตัดออกจากลำดับเทิร์น ที่ดินจะกลับเป็นของกลาง |
| FR-13 | เกมจบเมื่อเหลือผู้เล่นที่ไม่ล้มละลายคนเดียว จะประกาศผู้ชนะ |
| FR-14 | เซฟอัตโนมัติทุกจบเทิร์น และเล่นต่อจากเซฟได้ |
| FR-15 | แสดง Game Log และเลื่อนดูย้อนหลังได้ |
| FR-16 | มีเสียงประกอบเหตุการณ์สำคัญ |
| FR-17 | Test Mode ตั้งเงินสูงและวาร์ปตำแหน่งได้ |

## Non-Functional Requirements

| ID | ข้อกำหนด |
|---|---|
| NFR-1 | รันด้วย Bun ผ่าน terminal ไม่ต้องมี GUI |
| NFR-2 | ค่ากติกาทั้งหมดเป็นค่าคงที่ที่ปรับได้ที่จุดเดียว ( `Game.ts` ) |
| NFR-3 | Logic ของเกมทดสอบได้โดยไม่ต้องเปิด UI ( `bun run test` ) |
