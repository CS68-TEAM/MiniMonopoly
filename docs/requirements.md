# Requirements

รายการสิ่งที่ระบบต้องทำได้ ใช้เลข FR/NFR อ้างอิงจาก test หรือ commit ได้
รายละเอียดกติกาเชิงตัวเลขอยู่ที่ [spec.md](spec.md) (หัวข้อ 4)

## Functional Requirements

| ลำดับ | ข้อกำหนด |
|---|---|
| 1 | เกมมีผู้เล่น 4 คน ได้แก่ ผู้เล่น 1 คน บอท 3 ตัว (Easy, Normal, Hard) |
| 2 | ผู้เล่นทอยลูกเต๋า 1 ลูก (1–6) แล้วเดินบนกระดาน 32 ช่องแบบวนรอบ |
| 3 | ผู้เล่นได้รับ $250 เมื่อเดินผ่านหรือหยุดที่ GO |
| 4 | ซื้อที่ดินว่างที่ยืนอยู่ได้ ภายในข้อจำกัดเงิน จำนวนที่ดินที่ถือ (สูงสุด 5 แปลง) และซื้อที่ดินที่ไม่มีเจ้าของสูงสุด (สูงสุด 7  ครั้ง) |
| 5 | เหยียบที่ดินคนอื่นแล้วจ่ายค่าเช่าอัตโนมัติ |
| 6 | ยึดที่ดิน (takeover) จ่ายเพิ่ม 50% ของราคาเดิม จำกัด 1 ครั้ง/เกม/ผู้เล่น และต้องถือที่ดินไม่เกินจำนวนสูงสุด |
| 7 | ขายที่ดินคืนได้ 30% ของราคาซื้อ |
| 8 | ช่อง Tax เก็บ 15% ของเงินสดปัจจุบัน |
| 9 | ช่อง Chance สุ่มการ์ดตามความน่าจะเป็นแล้วมีผลทันที |
| 10 | Jail / Go Jail ติดคุก จ่ายประกันตัว $250 หรือข้ามเทิร์นแล้วรอออกเทิร์นหน้า |
| 11 | เงินติดลบ ผู้เล่นจะเลือกขายที่ดินทีละแปลงหรือประกาศล้มละลาย บอทขายอัตโนมัติ |
| 12 | ผู้เล่นที่ล้มละลายถูกตัดออกจากลำดับเทิร์น ที่ดินกลับเป็นของกลาง |
| 13 | เกมจบเมื่อเหลือผู้เล่นที่ไม่ล้มละลายคนเดียว และประกาศผู้ชนะ |
| 14 | เซฟอัตโนมัติทุกจบเทิร์น และเล่นต่อจากเซฟได้ |
| 15 | แสดง Game Log และเลื่อนดูย้อนหลังได้ |
| 16 | มีเสียงประกอบเหตุการณ์สำคัญ (เล่นผ่าน command prompt จึงจะมีเสียงเฉพาะบน Windows) |
| 17 | Test Mode สามารถตั้งเงินสูงและวาร์ปตำแหน่งได้ โดยไม่เซฟทับไฟล์จริง |

## Non-Functional Requirements

| ลำดับ | ข้อกำหนด |
|---|---|
| 1 | รันด้วย Bun ผ่าน terminal ไม่ต้องมี GUI |
| 2 | ค่ากติกาทั้งหมดเป็นค่าคงที่ที่ปรับได้ที่จุดเดียว (`Game.ts`, ดู [spec.md](spec.md) หัวข้อ 4) |
| 3 | Logic ของเกมทดสอบได้โดยไม่ต้องเปิด UI (`bun run test`) |
