# Spec — ข้อมูลจำเพาะทางเทคนิค (Mini Monopoly)

เอกสารนี้บอกว่าระบบสร้างด้วยเครื่องมืออะไร กติกาเชิงตัวเลขของเกมคืออะไร และต้องใช้สภาพแวดล้อมแบบไหนถึงจะรันได้
รายการสิ่งที่ระบบต้องทำได้ดูที่ [requirements.md](requirements.md)

---

## 1. Tech Stack

| หัวข้อ | รายละเอียด |
|---|---|
| Runtime | Bun |
| ภาษา | TypeScript (`strict`) |
| Interface | Console / TUI (ไม่มี GUI) |
| Paradigm | OOP (`Game`, `Player`, `Board`, `Property`, คลาส AI) ผสม FP (pure function เช่น `rollDice`, `movePosition`, `getTakeOverPrice`, `getBuyBlocker`, `pickChanceEvent`) |
| ข้อมูลกระดาน | `ui/Board32.ts` (`BOARD_32`) นิยามช่องทั้ง 32 ช่อง แล้ว `Board` แปลงเป็น `Tile` |
| Test framework | `bun:test` (built-in ของ Bun) |

> หมายเหตุ: ชื่อ TUI framework และเวอร์ชัน dependency ให้ตรวจกับ `package.json` จริงของโปรเจกต์แล้วเติมที่หัวข้อ 2

## 2. Libraries / Dependencies

โค้ดส่วน logic ของเกมไม่พึ่ง library ภายนอก ใช้เฉพาะ module มาตรฐานของ Node/Bun

| Module | ใช้ที่ | หน้าที่ |

## 4. กติกา (Game Constants)

ค่าทั้งหมดอยู่ที่ `Game.ts` (export const) ปรับได้ที่จุดเดียว ตามข้อ NFR-2

| ค่าคงที่ | ค่า | ความหมาย |
|---|---|---|
| จำนวนผู้เล่น | 4 | บังคับใน constructor ของ `Game` (ไม่ครบ 4 → throw error) |
| จำนวนช่อง | 32 | ความยาวของ `Board.tiles` |
| เงินเริ่มต้น | 1000 | default ของ `Player` |
| ลูกเต๋า | 1–6 | `rollDice()` ทอยลูกเดียว |
| `START_BONUS` | 200 | ได้เมื่อเดินผ่าน หรือหยุดที่ช่อง START |
| `JAIL_BAIL_AMOUNT` | 250 | ค่าประกันตัวออกจากคุก |
| `TAKEOVER_MULTIPLIER` | 1.5 | ราคายึดที่ดิน = `ceil(price × 1.5)` |
| `TAKEOVER_LIMIT` | 1 | ยึดได้ 1 ครั้ง/เกม/ผู้เล่น |
| `MAX_PROPERTIES` | 5 | ถือที่ดินได้สูงสุดพร้อมกัน |
| `MAX_DIRECT_PURCHASES` | 7 | ซื้อตรงได้สูงสุดตลอดเกม (นับสะสม ไม่ลดเมื่อขายคืน) |
| `SELL_RATE` | 0.3 | ขายคืนได้ `floor(price × 0.3)` |
| `TAX_RATE` | 0.15 | ช่อง Tax เก็บ `ceil(เงินสดปัจจุบัน × 0.15)` |
| ตำแหน่งคุก | ช่อง 8 | `goToJail` วาร์ปผู้เล่นไปช่อง 8 แล้วติดคุก |

### 4.1 ผู้เล่น

| id | ชื่อ (kind) | ควบคุมโดย |
|---|---|---|
| `human` | Human | ผู้เล่น |
| — | AI Easy | `EasyAI` |
| — | AI Normal | `NormalAI` |
| — | AI Hard | `HardAI` |

สถานะผู้เล่น: `active` → `jailed` → `bankrupt`

### 4.2 ชนิดช่อง (`TileType`)

| ชนิด | ผลเมื่อหยุดที่ช่อง |
|---|---|
| `start` | ได้ `START_BONUS` |
| `property` | ว่าง: ซื้อได้ / มีเจ้าของอื่น: จ่ายค่าเช่า (`rent`) / ของตัวเอง: ไม่เกิดอะไร |
| `tax` | จ่าย 15% ของเงินสดปัจจุบัน |
| `jail` | ติดคุก |
| `goToJail` | ย้ายไปช่อง 8 แล้วติดคุก |
| `chance` | จั่วการ์ด Chance ทันที |
| `parking` | ปลอดภัย ไม่เกิดอะไร |

### 4.3 การเดินและโบนัส START

- ตำแหน่งใหม่ = `(ตำแหน่งเดิม + แต้มเต๋า) mod 32` (รองรับก้าวถอยหลังด้วย)
- ได้ `START_BONUS` เมื่อ "เดินข้าม" GO (ตำแหน่งใหม่ < ตำแหน่งเดิม และไม่ใช่ช่อง 0) ส่วนการหยุดพอดีที่ช่อง 0 ได้โบนัสจากผล `start` ของช่อง (ไม่ซ้ำกัน)
- การย้ายด้วยการ์ด Chance และ Test Mode (`debugTeleport`) **ไม่ได้** โบนัสตอนผ่าน GO

### 4.4 คุก

1. ติดคุกจากช่อง `jail` / `goToJail`
2. เทิร์นถัดไปของคนที่ติดคุก:
   - ถ้าเคยข้ามเทิร์นแล้ว (`stayinjailed = true`) → ออกจากคุกแล้วทอยเต๋าเดินปกติ
   - ถ้าเลือกจ่ายประกัน (และมีเงิน ≥ 250) → จ่าย 250 แล้วทอยเต๋าเดินในเทิร์นนั้นเลย
   - ถ้าไม่จ่าย → ข้ามเทิร์น (ตั้ง `stayinjailed = true`)
3. Human เลือกเองว่าจะจ่ายประกันหรือไม่ บอทตัดสินด้วย `decideJail` (ดูหัวข้อ 5)

### 4.5 เงื่อนไขซื้อที่ดิน (`getBuyBlocker`)

ซื้อไม่ได้ถ้าข้อใดข้อหนึ่งเป็นจริง (ตรวจตามลำดับนี้)

1. ที่ดินมีเจ้าของแล้ว (`already owned`)
2. เงินไม่พอ (`not enough money`)
3. ถือที่ดินครบ 5 แปลงแล้ว (`max 5 properties`)
4. ซื้อตรงครบ 7 ครั้งแล้ว (`max 7 purchases`)

### 4.6 เงื่อนไขยึดที่ดิน (takeover)

ต้องผ่านทุกข้อ: ที่ดินมีเจ้าของอื่น, ผู้ยึดถือที่ดินน้อยกว่า 5 แปลง, เงินพอจ่ายราคา `ceil(price × 1.5)`, ผู้ยึดยังไม่เคยยึดในเกมนี้ ค่ายึดจ่ายให้เจ้าของเดิมเต็มจำนวน

### 4.7 เงินติดลบและล้มละลาย

- ค่าเช่า / Tax / การ์ด Chance ที่จ่ายเงินทำให้เงินติดลบ → เข้าสู่กระบวนการปิดหนี้
- **Human** ที่ยังมีที่ดิน: เข้าสถานะ `pendingDebt` เลือกขายทีละแปลง (ได้ 30%) จนเงิน ≥ 0 หรือประกาศล้มละลายเอง
- **บอท**: ขายอัตโนมัติตามลำดับความสำคัญ (`sellPriority`) จนเงิน ≥ 0
- ถ้าขายหมดแล้วยังติดลบ → ล้มละลาย: ที่ดินทั้งหมดกลับเป็นของกลาง (`owner = null`) เงินตั้งเป็น 0 และถูกข้ามในลำดับเทิร์น
- เกมจบเมื่อเหลือผู้เล่นที่ไม่ล้มละลายคนเดียว → คนนั้นเป็นผู้ชนะ

### 4.8 การ์ด Chance

ความน่าจะเป็นรวม = 1.00 (สุ่มแบบสะสม)

| การ์ด | โอกาส | ผล |
|---|---|---|
| Forward +5 | 10% | เดินหน้า 5 ช่อง แล้วประมวลผลช่องที่ตกใหม่ |
| Lucky Day | 12% | ได้ $100 |
| Medical Expenses | 13% | จ่าย $100 |
| Go to Start | 5% | ย้ายไปช่อง START (ช่อง 0) |
| Speed Ticket | 15% | จ่าย $50 |
| Property Inspection | 10% | จ่าย `(จำนวนที่ดินที่ถือ + 1) × 50` |
| Market Boom | 10% | ได้ `(จำนวนที่ดินที่ถือ + 1) × 50` |
| Unexpected Bill | 10% | จ่าย $150 |
| Lottery | 5% | ได้ $500 |
| Backward -3 | 10% | ถอยหลัง 3 ช่อง แล้วประมวลผลช่องที่ตกใหม่ |

หมายเหตุ: ถ้าการ์ดย้ายไปตกช่อง Chance อีกช่อง จะไม่จั่วซ้ำ

## 5. พฤติกรรมบอท

| หัวข้อ | Easy | Normal | Hard |
|---|---|---|---|
| ซื้อที่ว่าง | เงินเหลือหลังซื้อ ≥ 150 และ ROI > เกณฑ์ | เงินเหลือ ≥ 150, ค่าเช่า ≥ 30, ถือ < 5 แปลง | ซื้อทุกครั้งที่เงินพอ |
| ยึดที่ดิน | เมื่อ "ตามหลังคนรวยสุด", เงินเหลือ ≥ 150, ROI > เกณฑ์ | เงินเหลือ ≥ 150, ค่าเช่า ≥ 30, ถือ < 5 แปลง | ยึดทุกครั้งที่เงินพอ |
| จ่ายประกันคุก | เงินเหลือ ≥ 100 และ (ตามหลัง หรือถือ ≥ 3 แปลง) | เงินเหลือ ≥ 300 | ไม่จ่ายเลย |
| ลำดับขายเมื่อติดหนี้ | ROI (rent/price) ต่ำสุดก่อน | ค่าเช่าต่ำสุดก่อน | ราคาถูกสุดก่อน |

สูตร ROI ของ Easy: `rent × 4 − price × 0.25` เกณฑ์คือ 0 (นำอยู่) หรือ −20 (ตามหลัง)

ทุกบอทยังต้องผ่านข้อจำกัดของกติกาหลัก (`canBuy` / `takeOver`) เสมอ
