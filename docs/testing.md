# Testing

## รันเทส

```bash
bun run test
```

ไฟล์เทสหลัก: `tests/game_test_full.test.ts`

## Test Mode

ใช้สำหรับทดสอบเกมแบบเร็ว โดยไม่ต้องรอทอยลูกเต๋า

| ปุ่ม     | ทำอะไร                |
| -------- | --------------------- |
| `Ctrl+L` | เปิด/ปิด Test Mode    |
| `Ctrl+G` | วาร์ปไปช่องที่ต้องการ |

เมื่อเปิด Test Mode:

* ทุกคนมีเงิน `$9,999`
* ปิด Auto Save ชั่วคราว เพื่อไม่ให้ทับเซฟจริง
* จำนวนเงินกำหนดด้วย `TEST_MONEY` ใน `src/ui/App.ts`
* การวาร์ปจะไม่รับโบนัสจากการผ่าน START
