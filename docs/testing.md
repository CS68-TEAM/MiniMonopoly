# Testing

## รันเทส

```bash
bun run test
```

ไฟล์เทส : `tests/game_test_full.test.ts`


## Test Mode (สำหรับนักพัฒนา)

ใช้ลองเกมเร็วๆ โดยไม่ต้องรอทอยลูกเต๋า

| ปุ่ม | ทำอะไร |
|---|---|
| `Ctrl+L` | เปิด/ปิด Test Mode ตอนเปิดทุกคนมี $9,999 และ**ปิดการเซฟอัตโนมัติชั่วคราว** เพื่อไม่ให้ทับเซฟจริง |
| `Ctrl+G` | (ต้องเปิด Test Mode ก่อน) วาร์ปตัวเองไปช่องไหนก็ได้ |

- จำนวนเงินตอนเปิด Test Mode: ค่าคงที่ `TEST_MONEY` ใน `src/ui/App.ts`
- การวาร์ปใช้ `Game.debugTeleport()` แล้วให้ `land()` ทำงานต่อตามปกติ (ไม่ได้โบนัสผ่าน START)
